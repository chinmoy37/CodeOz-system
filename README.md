# CodeOz Enterprise Web Platform & Design System

A modern, high-performance web application and enterprise showcase for **CodeOz**, built with React 18, TypeScript, Tailwind CSS, Lucide Icons, and Vite.

---

## 🌟 Highlights & Features

- **Brand Visual Identity:** Precision engineered with Solar Orange (`#FF5A00`), Deep Dark (`#0B0F19`), Crisp White surfaces, and Space Grotesk / Inter typography.
- **Home Experience:**
  - Interactive SVG Infinity Journey Architecture (*Idea to Infinity*).
  - **3D Cylindrical Ring Gallery (`AuroraGallery`):** Interactive mouse velocity-based 3D rotation showcasing real enterprise dashboards, category filtering, card lift effect, center live preview, and fullscreen lightbox modal.
  - Enterprise metric ribbons & purpose-built platform previews.
- **About Us:**
  - Executive narrative: *"Software should feel simple."*
  - High-res product studio workspace imagery with friction-removal badge.
  - 5 core engineering value pillars & partner ecosystem tags.
  - **Integrated Agile Delivery Process:** 4 structured stages (*Discover, Build, Deploy, Evolve*).
- **Services & Capabilities:**
  - **What we do:** 6 core disciplines (Software Development, Mobile Apps, UI/UX, Cloud & DevOps, Cybersecurity, IT Consulting).
  - **Our expertise:** 4 core engineering capabilities + categorized full-stack technology table.
- **All Solutions (11 Specialized Systems):**
  - Hospital & Diagnostic Management System
  - Point of Sale (POS) & Smart Inventory
  - Payroll & Human Resource Management (HRMS)
  - Core Financial Accounting System
  - Multi-Vendor E-Commerce Platform
  - School & College Management System
  - Courier & Logistics Fleet Tracking
  - Pharmacy & Drug Store Management
  - Restaurant POS & Kitchen Display System (KDS)
  - Microfinance & Loan Management System
  - Real Estate & Property Development ERP
  - Each with real dashboard preview images, metrics, architecture specs, and granular operational modules.
- **Interactive Global Features:**
  - Universal text hover transition to Solar Orange (`#FF5A00`).
  - High-contrast Solar Orange themed global footer with crisp brand identity protection.
  - Full mobile responsive drawer navigation.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18.0.0 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone repository
git clone <your-github-repo-url>
cd <repo-folder>

# Install dependencies
npm install
```

### Development Server

```bash
# Start local development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Production Build

```bash
# Type check and build optimized bundle
npm run build

# Preview production build locally
npm run preview
```
